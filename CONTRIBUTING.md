# Contributing to CodeToAnim

Thank you for helping improve CodeToAnim. The project is maintained by Gururaj Naik.

## Before You Start

- Read `README.md` and `SECURITY.md`.
- Open an issue for a substantial feature or behavior change before starting work.
- Never include credentials, user data, production exports, or private deployment configuration in a pull request.

## Development

1. Create a focused branch from the default branch.
2. Install frontend and backend dependencies using the README instructions.
3. Keep changes scoped to the feature or fix.
4. Add or update tests when behavior changes.
5. Run the relevant lint, build, and syntax checks locally.

## Pull Requests

Include:

- What changed and why
- Any Supabase schema, environment, or deployment changes
- Validation commands and results
- Security or privacy considerations

Do not commit `node_modules`, virtual environments, build output, `.env` files, keys, or service-account files.
